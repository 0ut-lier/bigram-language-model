# Bigram Language Model from Scratch

A simple character-level Bigram Language Model built with Python and PyTorch.

This project explores the mathematical foundations of language modeling using character transition probabilities.

## Features

- Character-level tokenization
- Vocabulary creation
- Bigram counting
- Conditional probability
- Maximum Likelihood Estimation (MLE)
- Laplace smoothing
- Random text generation
- Log-likelihood
- Negative Log-Likelihood (NLL)
- Cross-entropy
- Bigram probability visualization
